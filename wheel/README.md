# Колесо пригод

Мобільна сторінка з колесом фортуни на 10 секторів: 🏍️ — «Тріп на Ендуро», 🧗 — «Мотузковий парк».

## Запуск

Найпростіше — відкрити `index.html` у браузері. Складання не потрібне: чисті HTML, CSS і JS без залежностей.

Щоб перевірити на реальному телефоні в тій самій Wi-Fi мережі:

```bash
docker compose up web       # http://localhost:8080 або http://<IP-компʼютера>:8080
```

Лінтер (за потреби):

```bash
docker compose run --rm lint
```

## Як це працює

Кути рахуються за годинниковою стрілкою від верхньої точки кола, стрілочка стоїть праворуч — тобто
на куті 90°. Сектор для виграшу обирається наперед, після чого обчислюється кінцевий кут повороту:
не менш ніж 6 повних обертів плюс той залишок, що підводить обраний сектор під стрілочку.

Попап зʼявляється через 667 мс після зупинки, і разом із ним із верхніх кутів вікна б'є конфеті —
власний canvas-салют без зовнішніх бібліотек. Канвас лежить поверх попапа з `pointer-events: none`,
тож клік по сірій області й далі закриває вікно. За `prefers-reduced-motion: reduce` салют не
запускається.

Обертання веде CSS-transition на 7 секунд із `cubic-bezier(0.22, 1, 0.36, 1)` — швидкий старт і довге
згасання. На відміну від `requestAnimationFrame`, transition не завмирає у згорнутій вкладці, а
страхувальний `setTimeout` гарантує, що стан завершиться навіть якщо `transitionend` не спрацює.
